# Spring Boot CRUD API

API REST desenvolvida com Java e Spring Boot para gerenciamento de produtos, colocando em prática conceitos fundamentais do desenvolvimento Back-end.

## 🚀 Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- Maven
- Postman

## ⚙️ Funcionalidades

- Listar todos os produtos
- Buscar produto por ID
- Cadastrar novos produtos
- Atualizar produtos existentes
- Excluir produtos

## 🔗 Endpoints

| Método HTTP | Endpoint | Descrição |
|---|---|---|
| GET | `/products` | Lista todos os produtos |
| GET | `/products/{id}` | Busca um produto por ID |
| POST | `/products` | Cadastra um produto |
| PUT | `/products/{id}` | Atualiza um produto |
| DELETE | `/products/{id}` | Exclui um produto |

## 📌 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar a criação de APIs REST utilizando Java e Spring Boot, explorando operações CRUD, requisições HTTP, acesso a dados e organização de uma aplicação Back-end.

O desenvolvimento foi realizado com apoio de um tutorial, complementando meus estudos e minha prática com a tecnologia.
